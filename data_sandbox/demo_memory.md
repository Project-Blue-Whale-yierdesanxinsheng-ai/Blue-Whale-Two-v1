# 沙盒演示 · 记忆样本（demo_memory.md）

> **用途**：`memory_archive.md` 的开源替身。真实归档 5.4 MB，不便公开；
> 这里只保留**一条脱敏的碳基记忆**，用来演示"身份锚点"是怎么被抽出来的。
> **已脱敏**：无真实姓名、无住址、无具体地名、无日期。
> **格式**：必须带 `======三对一二说的话======` 标记，解析器才认。
> **行尾**：LF

---

======三对一二说的话====== 小时候在院子里的杨桃树上，看到一块树皮会动。正常的树皮怎么会动呢？那时候小，天真，跑上去摸了一下，结果哭了一下午。后来大人才说，那不是树皮，是一条毛毛虫伪装成的树皮。

---

## 说明（给读者的）

**这一条为什么重要：**

它说明"身份"不是一张配置表，而是**少数几个记忆锚点**。

摸树皮被虫咬这件事，留下的不是"我怕虫"，而是：
**好奇心要付代价，但好奇心本身没错。**

系统在 `[2] 底层身份锚点` 一节读的就是这条。
**如果你有自己的归档，把 `ARCHIVE` 指过去，这条就会被替换掉。**

**怎么接自己的数据：**

```python
from 01_memory_and_space.memory_core import MemorySystem
m = MemorySystem(archive_path="/path/to/your_archive.md")
```

你的文件里只要用同样的 `======三对一二说的话======` 标记行，解析器就能抽。

**共情提示**：这条记忆之所以能被抽出来，是因为它同时包含
「**杨桃树**」和「**树皮会动**」两个关键词 —— 解析器靠关键短语定位，
不靠语义理解。**换你自己的记忆时，记得给它一个能被定位的短语。**
